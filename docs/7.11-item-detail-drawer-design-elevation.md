## Sardor's Scope — Drawer Shell + Overview Tab

### Shell Improvements

**Header:**
- Add a subtle left-side colored strip/border (2–3px, accent color) to reinforce the item's category color
- Item name: bump to `text-lg font-semibold`
- SKU: keep mono, reduce opacity slightly (`text-gray-400`)
- Close button: make it a proper icon button with `hover:bg-gray-100` and `rounded-lg` (already partially there — confirm `h-8 w-8` sizing)
- Add a faint separator or micro-badge showing the location name (e.g., "Brooklyn Warehouse") below the SKU

**Slide animation** (already correct in spec, verify implementation):
```
type: "spring", damping: 25, stiffness: 300
```

**Tab bar:**
- Active tab indicator already uses `layoutId="tab-indicator"` — keep this
- Tab labels: consider uppercase + tighter tracking for a Linear-style feel, or keep sentence case (team lead to decide direction)
- Overflow scrolling on narrow widths: already has `overflow-x-auto`

### Overview Tab Improvements

**Stats cards** (2-column grid):
- The `accent: true` flag on "Warehouse Boxes" and "Total Pieces" cards is currently unused — these should render with a distinct background, e.g., a subtle blue/indigo tint: `bg-indigo-50 border-indigo-200`
- All other cards: `bg-gray-50 border-gray-200`
- Values: increase to `text-2xl font-bold tabular-nums`
- Label: `text-[10px] font-semibold uppercase tracking-wider text-gray-400`
- Add a count-up animation on the accent cards (Framer Motion `useMotionValue` + `animate` from 0 to actual value, spring easing, 600ms)

**Category/label badges:**
- `category_name`: more prominent — pill with a solid colored background (use category color if available, else blue)
- `short_label`: keep as a secondary muted pill

## Munis's Scope — Stock, Shipments, Cost History, Price History Tabs

### Stock Tab — Warehouse Stock

**Current issues:**
- Mixed light/dark styles — stock table has `bg-gray-50` header inside a light container but no consistent card wrapping
- Storage space grouping works but the group headers look plain
- No hover state on rows is visually engaging

**Elevation changes:**

**Group headers:**
- Wrap each group in a rounded card container: `rounded-xl border border-gray-200 bg-white shadow-sm overflow-hidden`
- Group header row: `bg-gray-50 border-b border-gray-100 px-4 py-2.5`
- Group name: `text-xs font-semibold uppercase tracking-wider text-gray-600`
- Totals: right-aligned badge pills, e.g., `bg-indigo-50 text-indigo-700 rounded-full px-2.5 py-0.5 text-xs font-medium`

**Table rows:**
- Row hover: `hover:bg-indigo-50/30 transition-colors duration-100`
- Pallet label (`font-mono text-xs`): keep, add a subtle `text-gray-700`
- Status badge: already styled well — keep `StatusBadge` component as-is
- Add stagger fade-in animation on rows:
  ```
  initial={{ opacity: 0, y: 4 }}
  animate={{ opacity: 1, y: 0, transition: { duration: 0.2, delay: rowIndex * 0.03 } }}
  ```

**Empty state:** Replace the SVG icon with a warehouse/box icon that fits the context better.

---

### Shipments Tab — Shipment History

**Current issues:**
- Summary stat cards are good but don't have stagger animation
- Table rows have stagger but the expand animation could be smoother
- Expanded content background (`bg-gray-50/60`) blends into table — needs more visual contrast

**Elevation changes:**

**Summary stat cards:**
- Keep the 3-card grid layout
- Add stagger: cards animate in at `delay: i * 0.06`
- "Shipments" count card: add a subtle `bg-indigo-50 border-indigo-200` accent to make it the hero stat
- Weighted avg and total received: `bg-gray-50 border-gray-200`

**Table header:**
- Make column headers more visually distinct: `bg-gray-50/80 border-b border-gray-100`
- Consider adding a "PO Date" tooltip explaining it's the purchase order date vs actual arrival

**ShipmentRow — expandable:**
- Expand arrow rotation (already implemented: `rotate: expanded ? 90 : 0`) — keep, it's correct
- PO number font: `font-mono text-xs font-semibold text-gray-800` (bump weight)
- Row hover: `hover:bg-blue-50/30`
- MIXED badge: keep amber styling

**Expanded content (box config breakdown):**
- Increase visual separation: give the inner nested table a `ring-1 ring-gray-200` instead of just a border
- Inner table header: `bg-gray-50 text-[10px] font-semibold uppercase tracking-wider text-gray-400`
- Notes column: if empty ("—"), render as `text-gray-300` to reduce visual noise
- Expand/collapse accordion: smooth `height` transition via `AnimatePresence` (already in place — verify `height: "auto"` works correctly with content)

### Cost History Tab

**Current issues:**
- Visually functional but feels like a "draft" — the chart + table separation is good, but the header section needs more character
- `Net Change` card currently shows red for increases, green for decreases — this is **correct for cost tracking** (cost going up is bad), confirm with team lead

**Elevation changes:**

**Summary cards:**
- "Current Cost" card: make this the hero — larger value text (`text-2xl`), slightly wider, or give it a left-side accent border
- "Net Change" card: the color coding (red for up, green for down) is semantically correct for cost — add a small arrow icon (↑ / ↓) alongside the number
- Add count-up animation on "Current Cost" value on tab mount

**Chart area:**
- Chart container: already has `rounded-xl border bg-white shadow-sm` — good
- Chart title: change from generic "Unit Cost Over Time" to include the item name if short enough, or keep as-is
- Reference line: consider adding a `<ReferenceLine>` at the average cost value (dashed, gray) for context
- Animate chart in on tab focus: already done via `chartKey` state + `useEffect` — this is correct, ensure animation plays on every tab switch (not just item change)
- Legend: the manual "Before" / "After" legend below the chart is clean — keep

**Cost change table:**
- Delta column: add small arrow icon next to the delta value for quicker visual scanning
- Notes column: add if `r.notes` is available (not currently shown) — consider adding a "Notes" column
- The `.reverse()` on history (newest first) is correct for a change log

---

### Price History Tab

**Current issues:**
- Very similar structure to Cost History tab — risk of them looking identical
- Batch filter is a nice feature but the UI for it is minimal

**Elevation changes:**

**Visual differentiation from Cost History:**
- Use `#6366f1` (indigo) for the price chart line (already done) vs `#2563eb` (blue) for cost — this differentiation is good, keep
- Tab header area: add a small "Transfer Price" label/badge to make it immediately clear this is different from cost

**Summary cards:**
- Same pattern as Cost History — make "Current Price" the hero card
- Apply stagger animation on card entrance

**Batch filter chip:**
- When a batch filter is active, render a more prominent filter indicator: a chip with an × button at the top of the tab, styled like `bg-indigo-50 border border-indigo-200 text-indigo-700 text-xs rounded-full px-3 py-1`
- The "Batch ×N" button in table rows: make it look more like a clickable chip — add a hover state `hover:bg-indigo-100`

**Change log table:**
- Source badges: current pill styling is good — keep
- `change_reason` sub-label: render it more prominently when present (not all rows have it) — consider showing it in a tooltip on the source badge instead of as a sub-row to save vertical space
- Delta: same arrow icon treatment as Cost History tab

## Animation Specification (from Phase 7 doc)

These are the **exact specs** from the Phase 7 document — must be followed precisely:

| Element | Animation |
|---|---|
| Drawer slide-in | `type: "spring", damping: 25, stiffness: 300` |
| Tab content switch | Horizontal slide: `x: 8 → 0 enter`, `x: 0 → -8 exit`, `duration: 0.2` |
| Cost/Price chart | Draws in on tab focus (recharts `isAnimationActive: true, animationDuration: 1000`) |
| Expandable shipment rows | Smooth height accordion via `AnimatePresence`, `height: 0 → "auto"` |
| Expand arrow | Rotates 90° on expand (`animate={{ rotate: expanded ? 90 : 0 }}`) |
| Stat cards | Stagger fade-in: `delay: i * 0.06`, `duration: 0.22` |
